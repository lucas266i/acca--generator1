# Football Links Directory

Mini-directorio web de enlaces oficiales de fútbol.

Incluye FIFA, las seis confederaciones continentales y federaciones nacionales organizadas por continente, con buscador, orden A–Z/Z–A y diseño responsive.

## Publicación

La aplicación es estática y está preparada para GitHub Pages.

Repositorio: https://github.com/lucas266i/acca--generator1
